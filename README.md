## Habilidades tecnicas:
Iniciei recentemente meu estudos, estou cursando ás matérias:

**Algoritmos e Pensamento Computacional:** Foca na lógica para resolver problemas complexos. Você aprende a estruturar o raciocínio em etapas sequenciais (decomposição, reconhecimento de padrões e abstração) antes de escrever qualquer código.

**Desenvolvimento Front-End para Web:** Ensina a construir a interface visual de sites e aplicações web. Envolve o uso de HTML (estrutura), CSS (estilização e design) e JavaScript (interatividade e comportamento da página).

**Design Profissional:** Aborda conceitos de UI/UX (interface e experiência do usuário), focado em criar layouts intuitivos, acessíveis e visualmente agradáveis, priorizando a usabilidade do sistema.

**Modelagem de Banco de Dados:** Trata de como planejar e estruturar o armazenamento de informações de um sistema. Você aprende a criar modelos conceituais, lógicos e relacionais para organizar os dados de forma eficiente e sem duplicidades.
